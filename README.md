# TLEseq
'A unifying neuropathological spectrum underlies medial temporal lobe epilepsy'

## Overview

This repository contains R scripts and analysis workflows for investigating the molecular and spatial organization of the human hippocampus in temporal lobe epilepsy (TLE).

We use high-resolution, single-cell spatial transcriptomics generated with the 10x Genomics Xenium platform to examine cell-type composition, transcriptional states, and regional organization across hippocampal tissue from individuals with epilepsy and postmortem controls.

The repository is intended to document the computational analyses and support reproducibility. 


## Repository organization


| Folder | Contents |
| --- | --- |
| `1_MegaData/` | Dataset integration, global cell annotations, quality control, and sample-level analyses |
| `2_domain_analysis/` | Hippocampal domains, regional gene expression, and cell-type composition |
| `3_ExcitatoryNeurons_analysis/` | Excitatory neuron subtypes and related analyses |
| `4_InhibitoryNeurons_analysis/` | Inhibitory neuron subtypes and related analyses |
| `5_Microglia_analysis` | Microglial cell states and associated analyses |
| `6_Patien-level-clustering_analysis/` | Patient-level pseudobulk profiles, PCA, and normalization comparisons |

Individual scripts are numbered where execution order is relevant. Some workflows require outputs from earlier processing steps.
